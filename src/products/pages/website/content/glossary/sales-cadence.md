**Sales cadence** is a planned sequence of contacts with a prospect over a set period: which channel, which message and how many days apart.

## A simple LinkedIn cadence

1. Day 0: connection request with a short note
2. On acceptance: first message
3. Three days later: one follow-up
4. Five days after that: a short closing note

Then stop. A cadence has an end, and a reply should end it earlier, since nobody wants to receive scripted messages after answering.

## Why use one

It removes the guesswork about when to follow up, and it makes results comparable between campaigns. You can change one step at a time and see which change helped.

## In Spurly

A [sequence](/product/campaigns) is an ordered list of steps (visit, connect, message, follow, like, comment, endorse and wait), and it stops for a person when they reply. For wording, see [how to write a follow-up sequence](/blog/linkedin-follow-up-message-sequence). A close relative is the [drip campaign](/glossary/drip-campaign).
